type: check
when: "Every pull request: the header part applies to added or renamed .swift, .sh and .py files, the attribution part to every added line and commit message"
actions: "Mark the check unmet and name each file whose header is missing or wrong"
---

# New source files carry the author header

Every added or renamed `.swift` file opens with this header, with the file's own name and the
year it was created:

```swift
//
//  FileName.swift
//  Understudy
//
//  Created by Yousef Mohamed <youseef.elserwey@gmail.com>.
//  Copyright © 2026 Yousef Mohamed. MIT License.
//
```

A `.sh` or `.py` file has the same lines as `#` comments, after its `#!/usr/bin/env` line.

The check is met when each such file has the header, with the right file name. It fails when a
header names another author, or when any added line in the PR (a file, a comment or a commit
message) holds AI or tool attribution: a `Co-Authored-By` trailer naming an AI tool, a
`Claude-Session` line, or "Generated with" or "Generated by" followed by an AI tool's name.
Source fixtures inside string literals in tests are not files and need no header.
